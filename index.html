apk-drill

Security tooling

A single-machine pipeline that searches Android APKs for leaked secrets during authorized bug-bounty work. It downloads each APK, extracts it, scans it with TruffleHog (which checks whether found keys are still live), and writes a Markdown report with a remediation plan. Files are deleted after each package, and an error in one package doesn't stop the run.

scope → apkeep → extract → trufflehog → results.jsonl → report.md
  • Builds package lists from HackerOne, Bugcrowd, Intigriti and YesWeHack scopes, keeping only in-scope Android assets
  • Additional modules: API surface mapping, CORS and authorization probes, JWT analysis, SDK→CVE mapping, blast-radius estimates for leaked keys
  • Runs daily under cron on a home server; watches for app updates and new programs

Python · Bash · TruffleHog · apkeep · cron

Anki text-to-speech

Language learning

Adds spoken audio to Anki flashcards. You choose a deck; the script reads each note's Word or Sentence through AnkiConnect, generates speech with gTTS, saves it to the collection's media folder and fills in the card's Audio field. It started as a CSV-driven script and now has a desktop GUI.

  • Japanese, Mandarin, Korean, Spanish, French, Swedish, Arabic, English
  • Talks to Anki directly through AnkiConnect; no CSV exports needed
  • customtkinter GUI, so you don't have to edit the source to use it

Python · gTTS · AnkiConnect · customtkinter
